How to use these practice tests

Taking a test

  1. Pick a test from the Chapter test list. You can choose a single chapter (Ch. 1–28, grouped by book part), All chapters — full exam (all 161 questions), or All chapters — random 50.
  2. Optionally tick Shuffle question order, and choose a Pass mark (80% by default).
  3. Click Load test. Each question has four answers, A–D. Answer order is shuffled every time you load a test.
  4. Use Show answer on any question to see the correct answer, an explanation, and the Cisco document or study site it was checked against. Use Show all answers to study instead of testing.
  5. Click Submit test. If any questions are blank you'll be asked to confirm. Correct answers turn green and wrong picks turn red.

Reading your results

  • A PASS or FAIL verdict against your chosen pass mark, your score (for example 41/50), and the percentage correct, incorrect and unanswered.
  • For tests that span more than one chapter, a score for each chapter and a Chapters to study list showing every chapter below your pass mark, weakest first.
  • Click Retake to load a fresh, reshuffled version of the same test.

Practice without internet

  • Android (Chrome): tap Install app above, or use the ⋮ menu, then Install app or Add to Home screen.
  • iPhone / iPad (Safari): tap the Share button, then Add to Home Screen.
  • Windows / Mac (Chrome or Edge): click Install app, or the install icon in the address bar. On a Mac with Safari 17 or later, use File → Add to Dock.
  • After it's installed, the app works fully offline. You can also Download for offline use (a ZIP): unzip it and open index.html in any browser, no internet needed.

About the pass mark

Cisco doesn't publish a fixed passing score for 300-820, and it can change between exam versions. 80% is a sensible readiness target for practice. Raise it to 85–90% if you want a safety margin.
